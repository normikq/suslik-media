Доступ к Google Drive

Сервер медиатеки использует Google Drive владельца медиатеки как резервное хранилище уже подготовленных видеофайлов. Доступ запрашивается с разрешением drive.file: приложение видит и изменяет только файлы, которые создало само, — остальное содержимое Диска ему недоступно. Файлы хранятся в зашифрованном виде.

  • Данные из Google Drive используются только для хранения и воспроизведения видео этой медиатеки.
  • Они не передаются третьим лицам, не продаются и не используются для рекламы или обучения моделей.
  • Токен доступа хранится только на сервере медиатеки. Отозвать доступ можно в любой момент в настройках аккаунта Google (Безопасность → Сторонние приложения).

Использование информации, полученной через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Пользователи медиатеки

Для входа медиатека хранит минимум данных: идентификатор и имя аккаунта Discord (при входе через Discord), список устройств и место, на котором остановлен просмотр. Эти данные нужны только для работы медиатеки и не передаются третьим лицам. Удалить свои данные можно, обратившись к владельцу медиатеки.
