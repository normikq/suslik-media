# Отчёт о доработках (26.10.2026)

Ветка: `desktop-2.6.3-trackers`. Ничего не закоммичено и не выпущено. На телефоне, ТВ и в браузере не проверялось;
локально проверены: тесты `shared` (Gradle), `node --test tizen/test/*.test.js` (55 тестов), компиляция ПК и Android,
проверка синтаксиса JS сайта.

## 1. Слияние версий и сериалов в одну плитку

Раньше сливались только готовые одиночные фильмы, и только на ПК.

**Правила (везде одинаковые).** Фильмы сливаются с фильмами (общий постер, иначе название без пометок сезона + год),
сериалы и сборники — с сериалами (общий постер, иначе название без пометок сезона: `S01`, `Season 2`, `1-3 сезон`,
`Complete`). Сливаются только готовые раздачи. Нажатие на плитку с версиями открывает окно «Какую версию включить?»:
у сериала видно «Сезоны 1–3 · 24 серии», качество, размер, прогресс.

**Сериал или кинофраншиза.** Файлы, отличающиеся одним номером («Show - 01 [1080p].mkv»), считаются сериями, если в
названии раздачи есть сезон/серии либо это 5+ подряд пронумерованных файлов похожего размера. Трилогия
(«Film 1/2/3») остаётся сборником.

| Платформа | Что изменено |
|---|---|
| shared | `core/Model.kt`: `numberedEpisodesOf`, `titleKey`, `groupVersions`, `seriesLine`; тесты `SeriesGroupingTest.kt` |
| ПК | `VersionPicker.kt` (окно версий, `versionTarget`), `LibraryView.kt` |
| Android | новый `library/VersionPicker.kt` (нижний лист), `LibraryScreen.kt` (группировка, метка «N версии», закладка/избранное/метки по группе), `LibraryStore.kt` (пути постеров `posterPathOf`, фон. заполнение в `classifyAnimation`) |
| Tizen | `js/model.js` (`numberedEpisodesOf`, `titleKey`, `groupVersions`, `seriesLine`), `js/app.js` (плитка, диалог выбора, пути постеров в `localStorage`, фон. `posters.fill`), `js/ui.js` (`dialog(..., cls)`), `css/app.css`, тесты в `test/model.test.js` |
| Сайт | `public/index.html`: `numberedEpisodesOf`, `groupLibraryVersions`, `openVersionPicker`, `fillPosterPaths`; у плиток с версиями убрана быстрая кнопка воспроизведения |

Слияние по постеру добавлено после жалобы «не работает нигде кроме ПК»: на ПК версии с разными названиями склеивались
именно по постеру. Пути постеров запрашиваются в фоне (до 80 на Android и сайте, до 40 на Tizen), поэтому плитки
сливаются не мгновенно.

## 2. Поиск раздач как на ПК (кроме локального поиска)

Локальный поиск (RuTracker через браузер ПК, «Настройки трекеров», отсев «в раздаче нет видео») остаётся только на ПК.

Везде: понятное название, метки качества/кодека/HDR/источника/озвучки/коллекции, оценка нагрузки на сеть, пресеты
(«Мобильная сеть», «Оптимальные», «Макс. качество»), фильтр по качеству, сортировка (обычная по релевантности, лёгкие
сначала, по сидам), очистка запроса от слов «фильм», «скачать» и т. п., отсев игр/софта/музыки/трейлеров.

- **Android:** `SearchScreen.kt` переписан на общий код `shared` (`SearchHit`, `ReleaseParser`, `SearchFilterCriteria`);
  выдача по 25 с кнопкой «Показать ещё».
- **Tizen и сайт:** новый `searchcore.js` — перенос `ReleaseParser`/`SearchFilter`/`SearchHit` на ES2017 (без lookbehind и
  `\p{}`; границы слов для кириллицы — явными классами). Копии: `tizen/js/searchcore.js` и `website/public/searchcore.js`
  (правьте обе). Тесты: `tizen/test/searchcore.test.js` (16, по случаям `ReleaseParserTest`/`SearchFilterTest`).
  Tizen: `js/search.js`, `index.html`, `css/app.css`. Сайт: `index.html` (списки «Пресет» и «Качество», метки в строке
  результата; прежние «RU сначала» и «По дате» заменены набором как на ПК).

## 3. Исправления по логам

- **Падение Android при поиске** (`logcat` 11:49): `PatternSyntaxException` на `(?iU)…` в `SearchQueryCleaner` —
  Android не принимает инлайн-флаг `U`. `SearchFilter.kt`: регулярка очистки запроса через `ReleaseParser.uRegex`;
  `ReleaseParser.kt`: `uRegex` при отказе от `UNICODE_CHARACTER_CLASS` компилирует без него (на Android `\b` и так
  понимает кириллицу).
- **Клавиатура в 20 fps** (причина найдена по коду, в логах кадры не записаны):
  - `MainActivity.kt`: корневой отступ `safeDrawing` включал высоту клавиатуры, и весь экран заново измерялся на каждом
    кадре её анимации — теперь `safeDrawing.exclude(ime)`; флаг `imeVisible` читается через `derivedStateOf`.
    Побочный эффект: поле ввода не поднимает содержимое над клавиатурой (на экране входа свой `imePadding`).
  - `SearchScreen.kt`: результаты фильтруются и сортируются через `remember` по смене данных, а не на каждой
    перекомпоновке.

## 5. Замечания и риски

- `website/` правился по прямой просьбе («веб-версия»); на сервер не выкладывалось. Пуш в `main` публикует changelog сайта.
- Концы строк: в `tizen/css/app.css`, `tizen/js/{app,model,ui}.js` рабочая копия в CRLF, git при добавлении нормализует
  в LF — в диффе будут предупреждения, содержательных расхождений нет.
- Не проверено на устройствах: слияние по постеру на Android/Tizen/сайте, поиск на Android после исправления падения,
  плавность клавиатуры.
- Не перенесено на мобильные платформы: проверка «в раздаче нет видео» после добавления.
- Если плитки не сливаются, возможно, у сервера для этих раздач разные постеры.
