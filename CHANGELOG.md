# Changelog Suslik Media

## [2.6.3] — 2026-10-26

### 🚀 Прямой поиск на RuTracker с ПК
- **Поиск без ограничений**: теперь раздачи с RuTracker можно искать напрямую с вашего компьютера, даже если сайт заблокирован провайдером или защищен Cloudflare Turnstile.
- **Полная фоновая работа**: поиск и скачивание `.torrent`-файлов происходят в изолированном скрытом рабочем столе Windows (`SuslikHiddenDesktop`) — без всплывающих окон, мигающих вкладок или значков на панели задач.
- **Бережное отношение к ресурсам**: фоновые процессы браузера гарантированно завершаются сразу после выполнения поиска или загрузки файла.

### 🔑 Поддержка популярных браузеров для входа в 1 клик
- **Автоопределение браузеров**: приложение автоматически находит установленные браузеры: **Google Chrome**, **Яндекс Браузер**, **Microsoft Edge**, **Brave**, **Opera**, **Vivaldi** и **Firefox**.
- **Обход современной защиты Windows (App-Bound Encryption v20)**: в Chrome и Edge куки защищены шифрованием Windows — теперь вам не нужно вручную копировать токены из консоли разработчика. Нажмите кнопку «Войти через браузер», войдите в свой аккаунт, и сессия сохранится в приложении автоматически.
- **Поддержка Mozilla Firefox**: прямое безопасное чтение сессии из локального профиля Firefox.

### ⚙️ Управление трекерами в окне поиска
- В окне поиска появилась кнопка **«Трекеры (ПК ✓)»** с удобным меню:
  - **Локальные трекеры**: ввод и автоподбор куков для RuTracker, проверка подключения в реальном времени.
  - **Выбор трекеров**: переключатели для каждого отдельного трекера (Rutor, RuTracker, NNM-Club, Kinozal, The Pirate Bay, Nyaa) — отключайте ненужные источники для более быстрого поиска.

### 🛡️ Проверка файлов при ручном добавлении
- При добавлении торрент-файлов или magnet-ссылок приложение автоматически проверяет список файлов внутри раздачи:
  - Если раздача не содержит видео (например, это компьютерная игра, музыкальный альбом или программа), добавление отклоняется с понятным предупреждением.

### 🎯 Умная фильтрация и ранжирование выдачи
- **Без мусора и фейков**: из результатов поиска автоматически отсекаются тизеры, трейлеры, игровые релизы (FPKG, RePack, GOG, FitGirl) и фейковые раздачи еще не вышедших фильмов.
- **Очистка стоп-слов**: слова вроде «фильмы», «сериал», «смотреть», «в хорошем качестве» автоматически отсекаются, улучшая точность поиска.
- **Честный рейтинг раздач**:
  - Точное совпадение названия фильма и года выпуска поднимает раздачу на первые места.
  - Экранки (CAM / TS) и мертвые раздачи без раздающих опускаются в самый конец списка.

### 🐛 Исправления на трекерах
- **Rutor**: исправлена проблема, из-за которой поиск фильма с указанием года возвращал 0 результатов из-за особенностей поискового движка трекера.
- **NNM-Club**: исправлена ошибка кодировки кириллических запросов, из-за которой вместо нужного фильма выводились случайные раздачи 2012 года.
