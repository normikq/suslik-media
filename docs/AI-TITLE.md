# «Определить через ИИ» — что добавлено и изменено

27.10.2026

## Коротко

В карточке раздачи появилась кнопка «Определить через ИИ»: Gemini (`gemini-3.5-flash-lite`) по названию раздачи и путям видеофайлов предлагает название, тип (фильм, сериал, сборник), сезон, оригинальное название и год. После «Принять» это меняет название плитки, поиск постера, серии и слияние версий; регулярки остаются основным путём.

| Ветка | PR | Что внутри |
| --- | --- | --- |
| `feature/ai-title` | [normikq/suslik-media#45](https://github.com/normikq/suslik-media/pull/45) | сервер (`website/`), сайт, прогон на модели |
| `feature/ai-title-apps` | [normikq/suslik-media#46](https://github.com/normikq/suslik-media/pull/46) | `shared/`, ПК, Tizen |

Оба PR влиты в `main` (27.10) вместе с правками по обзору кода (раздел «Правки по обзору»). Проверено: модульные тесты сервера (150, 146 прошли, остальные пропущены), Tizen (62), наборы `shared` (в том числе `AiTitleSearchGroupingTest`); ПК компилируется; прогон на настоящей модели — 39 из 39 раздач. Не проверено: живой сервер с ключом, поиск постера на настоящем TMDB, сборки на устройствах. Сервер не выложен, сборки не выпущены.

## Как это выглядит для пользователя

Кнопку видит тот, кто добавил готовую раздачу (по `owners.json`), и админ библиотеки. Один запрос спрашивает обо всех своих раздачах плитки сразу (версии и сезоны), у каждой свой ответ.

Путь от кнопки до плитки: **кнопка** (тому, кто добавил) → **сервер** (кулдаун, лимит) → **Gemini** (все версии плитки одним вызовом) → **проверка** (сезон, название) → **предложение** (хранится на сервере) → **«Принять»** (галочка в окне) → русское название на плитке, постер по «оригинал (год)», тип и сезон в плеере, слияние версий по названию.

- **ПК:** пункт «Определить через ИИ» в меню плитки (правый клик). Ответ сразу открывается окном: строка на раздачу, галочка — взять ответ ИИ, «Сохранить». Позже окно открывается пунктом «Предложения ИИ…».
- **Сайт:** кнопка в карточке раздачи, предложения по каждой версии с «Принять / Отклонить» и «Принять все».
- **Кулдаун:** во время ожидания кнопка показывает «ИИ — через N мин», а не ошибку. У админа кулдауна нет.
- **Подпись предложения:** «Дюна» (Dune, 2021) · фильм — видно название, оригинал и год для постера, тип и сезон.
- **Пока не принято,** ничего не меняется. После «Принять» — без перезагрузки медиатеки. На плитке остаётся русское название, оригинал идёт только в поиск постера.

## Сервер (`website/`, PR #45)

Вся логика вызова и хранения — в новом модуле `src/services/aititle.js`; ключ только в переменной `GEMINI_API_KEY` сервера.

| Файл | Что сделано |
| --- | --- |
| `src/services/aititle.js` (новый) | вызов Gemini REST `v1beta`, `temperature: 0`, JSON-схема; проверка ответа; хранилище; кулдаун и дневной лимит; счётчики для замера |
| `src/routes/aititle.js` (новый) | маршруты (таблица ниже) |
| `src/services/favorites.js` | в ответе `/api/library`: `aiTitle` и `canAiTitle` у раздачи, `aiTitleReadyAt` сверху |
| `src/services/downloads.js` | `ownerChecker` — «добавил сам или админ» по `owners.json` |
| `src/services/posters.js` | «Название (год)»: поиск без года, результат TMDB того же года (±1) |
| `src/services/cleanup.js` | удалённая раздача забывает связь с ответом |
| `src/config.js`, `.env.example` | настройки (раздел «Выкладка») |
| `test/aititle.test.js`, `test/posters-year.test.js` (новые) | тесты с моком `fetch` и TMDB, без настоящих ключей |
| `scripts/aititle-eval.js` (новый) | прогон набора раздач на настоящей модели |

| Маршрут | Кто | Что делает |
| --- | --- | --- |
| `POST /api/library/ai-title` `{ids, force?}` | добавивший, админ | раздачи плитки (до 10) одним вызовом; `force` — спросить заново, только админ |
| `POST /api/library/:id/ai-title` | добавивший, админ | то же для одной раздачи |
| `POST /api/library/:id/ai-title/decision` `{accept}` | добавивший, админ | принять или отклонить предложение |
| `POST /api/library/ai-title/decision` `{decisions:[{id, accept}]}` | добавивший, админ | то же для нескольких раздач одним запросом; без предложения и чужие пропускаются (сайт: «Принять все») |
| `GET /api/ai-title/stats` | админ | вызовы, 429/503, токены за день, принятые и отклонённые |

**Ответ модели** на каждую раздачу: `base` (название для показа, по-русски, транслит — кириллицей), `original` и `year` (для постера), `kind` (`movie` / `series` / `collection`), `season`.

**Проверка ответа:**

- если в раздаче есть пометки сезона (`S02`, «2 сезон», «1-3 сезон»), сезон от ИИ должен с ними совпадать;
- пометок нет — сезон модели, кроме взятого из года («2022» → 22), звука «5.1», разрешения;
- сериал «Название 2 - 01» без пометок: число после названия, которого нет в названии от ИИ, — сезон; после «Part», «Часть», «Cour», «Vol» — нет;
- числа, которые не сезон: разрешение, кодек, `4K`/`8K`/`3D`, `10-bit`, `HDR10`, звук `X.Y` (5.1, 7.2), год;
- у фильма и сборника сезона нет; точки вместо пробелов убираются; без ответа — статус `none`.

**Защита запроса:** название и пути перед отправкой в модель очищаются от переводов строк и управляющих символов (иначе имя раздачи подделало бы «Раздача N» и чужой ответ). Если Gemini заблокировал запрос (`SAFETY`, `PROHIBITED_CONTENT` и т. п.), причина пишется в журнал, результат — `none`.

**Хранилище** `ai-titles.json`: ключ — нормализованное название плюс состав видеофайлов. Ответ считается один раз; копии раздачи и та же раздача, добавленная заново, получают его без вызова. Запись атомарная (временный файл и замена), как у `sync.json`; копии `.bak` нет. Версия ответа — 6: ответы старых версий помечены `stale`, их можно спросить заново — кроме принятых и отклонённых: решение владельца от смены версии не теряется (переспросить его может только админ через `force`). Ответ общий для всех копий раздачи с тем же ключом: «Принять» или «Отменить» у одной копии меняет его и для остальных, в том числе добавленных другими пользователями. Результат `none` хранится, но через час его тоже можно спросить заново. При вытеснении старых записей (больше 5000) принятые названия не удаляются.

**Лимиты:** кулдаун 15 минут на пользователя (у админа нет), общий дневной лимит 200 вызовов (и для админа). Ответы Gemini 429 и 5xx (500, 502, 503, 504), таймаут и сеть попытку не списывают; прочие ошибки (ключ, запрос) списывают, чтобы сломанный ключ не дёргался без конца. Раздача, которую уже спрашивает другой запрос, второй раз в модель не уходит (ждёт и берёт тот ответ). Отсидевшие кулдаун записи удаляются. Расход токенов из `usageMetadata` пишется в журнал по каждому вызову.

## Клиенты

Принятый ответ применяется одинаково везде: логика в `shared` и две её копии (сайт, Tizen), паритет поддерживается вручную и проверяется тестами.

| Клиент | Файлы | Что сделано |
| --- | --- | --- |
| Общий модуль (PR #46) | `shared/.../core/Model.kt`, `ModelTest.kt` | `AiTitle` в `Magnet`; `prepareItems` берёт принятое название для плитки и «оригинал (год)» первым запросом постера; `buildPlayable` применяет тип и сезон (`applyAiTitle`); `withAiTitle` — «Принять» без перезагрузки |
| ПК (PR #46) | `Library.kt`, `LibraryView.kt`, `AiTitleDialog.kt` (новый), `strings/ru.json` | пункты в меню плитки, окно с галочками, постер ищется заново после смены названия; ошибка одной раздачи не останавливает сохранение остальных; сохранение решений не обрывается закрытием окна (`NonCancellable`) |
| Сайт (PR #45) | `public/index.html`, `public/redesign.css` | блок ИИ в карточке; `displayTitle`, `aiPosterQuery`, `applyAiTitle` — те же правила, что в `shared`; «Принять все» одним запросом, кнопка ИИ сама оживает по окончании кулдауна |
| Tizen (PR #46) | `tizen/js/model.js`, `tizen/test/model.test.js` | то же, что в `shared`, без кнопки (показ принятого) |
| Android | — | кнопки нет; принятые ответы применяются автоматически через `shared` |

**Поиск и слияние версий:** принятое название и оригинал входят в `searchText` (поиск находит «Фрирен», даже если раздача названа `Sousou.no.Frieren`); у фильма в ключе слияния год принятого ответа ИИ важнее года в имени раздачи, поэтому `Dune.2021` и `Dune.BDRip` — одна плитка. Пока предложение не принято, поиск и слияние его не видят.

**Тип и сезон после «Принять»** (поверх разбора по файлам):

- «сериал» — все видео по порядку имён становятся сериями одного сезона, если по файлам вышел сборник или фильм;
- «сборник» — отдельные фильмы с названиями; «фильм» — играет главный файл;
- сезон подставляется, только если сезон в раздаче один; сезоны по папкам не трогает;
- за этим идут выбор серий, плеер, категория плитки и слияние версий.

## Прогон на настоящей модели

После правок модель верно определяет 39 из 39 раздач по типу, сезону и названию; до правок было 26 из 29. Прогон — `website/scripts/aititle-eval.js`, тот же путь, что на сервере (промпт, схема, проверка), ключ из `GEMINI_API_KEY` или `GEMINI_API`.

**Набор (39 раздач):** коллекции по годам (Гарри Поттер, «Миссия невыполнима» с файлами-годами, «Пила 1-10», «Форсаж», «Звёздные войны I-IX»); сериалы с годами вместо сезонов («Фарго» с папками-годами, «Доктор Кто 2024», «Ted.Lasso.2023»); названия-годы («1923», «2012», «Бегущий по лезвию 2049»); «Cyberpunk Edgerunners 2 - 01», «Final Season Part 2», «Mob Psycho 100 III»; «11 сезон: 1-24 серии», транслит; все сезоны в одной раздаче; шоу по датам; плитки из нескольких раздач одним вызовом.

| Прогон | Верно | Что не так |
| --- | --- | --- |
| 6 (оригинал и год) | 39 из 39; оригинал 31 из 31, год 30 из 31 | «Фрирен» — 2024 вместо 2023, в пределах ±1 поиска постера |
| 5 | 38 из 39 | «Фрирен» — часть официального русского названия (эталон расширен) |
| 4 | 39 из 39 | — |
| 3 | 39 из 39 | «Матрица Трилогия» в названии сборника — эталон не ловил, промпт поправлен |
| 2 | 38 из 39 | «Ted.Lasso.2023» → сезон 3 (верно: третий сезон вышел в 2023-м; эталон поправлен) |
| 1 (до правок) | 26 из 29 | «Final Season Part 2» → сезон 2 вместо 4 (ошибка правила сервера); 429 от Gemini |

**Что нашли и исправили:**

- сервер обнулял сезон без пометок в раздаче (три раздачи Cyberpunk из четырёх в библиотеке);
- правило «число после названия = сезон» перебивало модель на «Part 2»;
- копии одной раздачи получали ответ, но «Принять» отвечал «Предложения ИИ для этой раздачи нет»;
- слова «трилогия / коллекция» в названии мешали слиянию сборника с фильмом.

Год модель ни разу не превратила в сезон по цифрам; если сопоставляет год с сезоном, то по знаниям и верно («Doctor Who 2024» — сезон 1). **Расход:** в среднем 617 токенов на вход и 43 на выход на вызов (до поля original/year), группа из четырёх раздач — около 1270 на вход.
