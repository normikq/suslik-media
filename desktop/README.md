# Suslik Media — приложение для Windows

> 📖 **Полная архитектурная документация:** [docs/DESKTOP.md](../docs/DESKTOP.md)

Плеер на Compose Desktop на базе высокопроизводительного нативного движка **mpv** (видео и панели — в единой сцене окна Skiko OpenGL, аппаратное декодирование): воспроизводит MKV, HEVC/H.265, 4K HDR, AV1, многоканальный звук AC3/E-AC3/DTS/TrueHD, внешние и встроенные стилизованные субтитры (libass). Сервер только отдаёт ссылки, видео не перекодируется.

## Движок воспроизведения
Воспроизведение осуществляется через **mpv**:
- Видео рисуется в той же сцене Compose, что и интерфейс: `vo=libmpv` + render API в OpenGL-контексте окна (Skiko), прямо в текстуру Skia — кадр не копируется (`player/MpvVideo.kt`). Аппаратное декодирование `hwdec=auto-safe` (на NVIDIA — nvdec).
- Панели Liquid Glass (`PlayerTopBar`, `PlayerBottomBar`, списки серий, меню звука/субтитров) — обычные слои Compose поверх видео, без отдельных окон: нет потери кликов и фокуса, смещений при полном экране и DPI > 100 %.
- Идеальная поддержка стилизованных ASS/SSA субтитров (`libass`) с мгновенным изменением масштаба шрифта на лету.
- Ищет `libmpv-2.dll` в `%APPDATA%\SuslikMedia\mpv\`, рядом с `.exe` (`mpv/` или папке приложения), либо по переменной `SUSLIK_MPV_DIR`. При отсутствии библиотека автоматически загружается и проверяется по контрольной сумме SHA-256.

## Что нужно
- Для работы плеера: библиотека `libmpv-2.dll` (x86_64, загружается установщиком/приложением автоматически).
- Для сборки: **IntelliJ IDEA** (Community или Ultimate) или Android Studio, JDK 17 или 21.

## Запуск и сборка
Адрес сервера в репозитории не хранится: `SITE_URL` из окружения (в CI — секрет) или `suslik.siteUrl` в
`~/.gradle/gradle.properties` — домен и, если сервер не в корне, путь (`https://<домен>[/<путь>]`). В приложение он попадает как
`-Dsuslik.site`, в установщик — `-p:SiteUrl`. Без него `run`/`package*` останавливаются с ошибкой.

1. Открыть проект в IDE → дождаться синхронизации Gradle.
2. Запуск: задача Gradle `desktop:run` (или в терминале `desktop/gradlew.bat run`).
3. Сборка отладочного MSI: `.\install-desktop-debug.ps1` (собирает пакет с флагом `-Pdiag` и устанавливает `Suslik Debug`).
4. Релизный MSI: `desktop/gradlew.bat packageMsi` → `desktop/build/compose/binaries/main/msi/`; установщик для людей и обновлений
   (`Suslik Media Setup-<V>.exe`, MSI внутри) собирает `desktop.yml` из `desktop/setup` (см. `docs/DESKTOP.md` §9).

## Возможности плеера
- Аппаратный 4K HDR вывод с аппаратным декодированием (`hwdec=auto-safe`).
- Единый интерфейс («жидкое стекло», выплывающая капсула громкости, пропуск заставки, шторки дорожек).
- Предзагруженный буфер и кольцевой дисковый кэш (`BurstProxy`).
- Автоматический выбор предпочтительного языка дорожки и субтитров с сохранением выбора для каждого сериала.
- Режим мини-плеера (PiP) в углу экрана с возможностью перетаскивания.
- Горячие клавиши: Пробел/K — пауза, ←/→ — ±10 с (Shift — ±60 с), ↑/↓ — громкость, F/Enter — полный экран, Esc — выход, N/P — следующая/предыдущая серия, M — звук вкл/выкл, S — пропуск заставки, T — поверх окон, O — мини-плеер. Двойной клик — полный экран, колесо мыши — громкость.
