# Suslik Media — приложение для Windows

> 📖 **Полная архитектурная документация:** [docs/DESKTOP.md](../docs/DESKTOP.md)

Плеер на Compose Desktop с поддержкой современного движка **mpv** (аппаратный Direct3D 11 рендеринг в едином окне) и классического резервного движка **VLC** (vlcj): воспроизводит MKV, HEVC/H.265, 4K HDR, AV1, многоканальный звук AC3/E-AC3/DTS/TrueHD, внешние и встроенные стилизованные субтитры (libass). Сервер только отдаёт ссылки, видео не перекодируется.

## Движки воспроизведения
Приложение поддерживает выбор движка в «Настройках» медиатеки:
1. **mpv (Direct3D 11 / аппаратное ускорение) — по умолчанию:**
   - Видео выводится аппаратно напрямую через Direct3D 11 в нативный Win32 Canvas окна (`vo=gpu`, `gpu-api=d3d11`, `hwdec=auto-safe`).
   - Прозрачный оверлей интерфейса Liquid Glass (`PlayerTopBar`, `PlayerBottomBar`, списки серий, меню звука/субтитров) поверх видеопотока без задержек и с 0% нагрузки на процессор.
   - Идеальная поддержка стилизованных ASS/SSA субтитров (`libass`) с мгновенным изменением масштаба шрифта на лету.
   - Ищет `libmpv-2.dll` в `%APPDATA%\SuslikMedia\mpv\`, рядом с `.exe` (`mpv/` или папке приложения), либо по переменной `SUSLIK_MPV_DIR`.
2. **VLC (vlcj / Classic) — резервный режим:**
   - Встраивание через системный Win32 AWT `Canvas` с двухоконным прозрачным оверлеем интерфейса.
   - Используется автоматически, если `libmpv-2.dll` не найдена в системе, либо при явном выборе в «Настройках».

## Что нужно
- Для **mpv** (основной режим): библиотека `libmpv-2.dll` (x86_64).
- Для **VLC** (резервный режим): установленный **VLC 3.x для Windows, 64-bit** — https://www.videolan.org/vlc/.
- Для сборки: **IntelliJ IDEA** (Community или Ultimate) или Android Studio, JDK 17 или 21.

## Запуск и сборка
1. Открыть проект в IDE → дождаться синхронизации Gradle.
2. Запуск: задача Gradle `desktop:run` (или в терминале `desktop/gradlew.bat run`).
3. Сборка отладочного MSI: `.\install-desktop-debug.ps1` (собирает пакет с флагом `-Pdiag` и устанавливает `Suslik Debug`).
4. Релизный установщик: `desktop/gradlew.bat packageMsi` → `desktop/build/compose/binaries/main/msi/`.

## Возможности плеера
- Аппаратный 4K HDR вывод с аппаратным декодированием (`hwdec=auto-safe`).
- Единый интерфейс («жидкое стекло», выплывающая капсула громкости, пропуск заставки, шторки дорожек).
- Предзагруженный буфер и кольцевой дисковый кэш (`BurstProxy`).
- Автоматический выбор предпочтительного языка дорожки и субтитров с сохранением выбора для каждого сериала.
- Режим мини-плеера (PiP) в углу экрана с возможностью перетаскивания.
- Быстрое переключение движков в «Настройках».
- Горячие клавиши: Пробел/K — пауза, ←/→ — ±10 с (Shift — ±60 с), ↑/↓ — громкость, F/Enter — полный экран, Esc — выход, N/P — следующая/предыдущая серия, M — звук вкл/выкл, S — пропуск заставки, T — поверх окон, O — мини-плеер. Двойной клик — полный экран, колесо мыши — громкость.
