# Suslik Media — приложение для Windows (1.0.0, первая версия)

Нативная библиотека (как в Android 1.3) + плеер на VLC: играет MKV/HEVC/AC3/DTS, дорожки, субтитры — всё, что играет VLC. Сервер только отдаёт ссылки, видео он не перекодирует.

## Что нужно
- **VLC 3.x для Windows, 64-bit** — https://www.videolan.org/vlc/ (приложение берёт его движок).
- Для сборки: **IntelliJ IDEA** (Community подойдёт) или Android Studio, JDK 17 или 21.

## Запуск и сборка
1. Открыть папку `suslik-desktop` в IntelliJ IDEA → дождаться синхронизации Gradle (скачает Compose Desktop и vlcj).
2. Запуск: вкладка Gradle → `compose desktop` → **run** (или в терминале `gradlew run`).
3. Установщик: `gradlew packageMsi` (или `packageExe`) → `build/compose/binaries/main/msi/`. Для `packageMsi` JDK должен быть полным (не JRE), WiX Toolset Gradle-плагин скачает сам.

## Что умеет
- Вход общим паролем (сессия хранится в `%APPDATA%\SuslikMedia`), библиотека с постерами (кэш на диске), сезоны/серии, «Продолжить …», полоска просмотра, «разрешение · битрейт», «Отменить/Удалить».
- Выбор источника: зеркало (с плейлистом сезона) или напрямую; копирование ссылки.
- Плеер: пауза/перемотка, полоса времени, громкость до 150%, озвучка и субтитры (выбор запоминается для сериала), субтитры из папки раздачи, следующая серия с отсчётом 10 с, продолжение с места, переподключение при обрыве, полноэкранный режим с автоскрытием панели.
- Клавиши: Пробел/K — пауза, ←/→ — ±10 с (Shift — ±60 с), ↑/↓ — громкость, F/Enter — полный экран, Esc — выйти из него, N/P — следующая/предыдущая серия, M — без звука. Клик по видео — пауза, двойной клик — полный экран.
- Поиск раздач прямо в приложении (вкладка «Поиск раздач»): трекеры, фильтры, «＋ В библиотеку» со статусом загрузки.

## Ограничения первой версии
- Видео рисует сам VLC прямо в окно приложения (исходное разрешение, аппаратное декодирование, без копирования кадров). Панель управления — под видео; в полноэкранном режиме прячется через 3 с, появляется при движении мыши.
- Код не компилировался автором — первая сборка у вас; при ошибке пришлите текст.
