# Отложенные задачи (договорились сделать позже)

## Запас (BurstProxy) — ограничить размер и трафик
Решение владельца (12.10.2026): больше 128 МБ запаса не оставлять — смысла мало, только больше нагрузка на сервер.
- ~~Пресеты «Запас»: максимум 128 МБ~~ — сделано (Android 2.0.1, Windows 2.0.2): 160/256/512 убраны, старые значения опускаются до 128.
  Позже (2.1.1) решение пересмотрено: для тяжёлых 4K и Remux вернули пресеты 160 и 256 МБ (`PlaybackPresets.kt`, `BURST_MAX` = 256 МБ). Сейчас верхняя граница — 256 МБ.
- На мобильном интернете автоматически меньше (например, 64 МБ), на Wi-Fi — выбранное в «Настройках».
- После перемотки «разгон» запаса ограничить ~32 МБ, пока не ясно, что смотрят дальше, а не перематывают снова
  (сейчас новое окно качает до заполнения кольца, при частых перемотках это теряется).
- Код: shared/src/main/kotlin/ru/suslikovanora/media/core/BurstProxy.kt, PlaybackPresets.kt; настройки в обоих приложениях.

## Discord и совместный просмотр (после ПК 2.5.0)
- Права админа: подключить `requireAdmin` — видеть и отключать устройства (удалять чужие раздачи админ Discord уже может, `removeChecker`).
- «Мои фильмы» на сайте (Android — сделано в 2.5.0; сервер готов: `/api/shelf`, флаг `mine`); приватные раздачи и «скрыть у меня» не делались.
- Перенос старых раздач на пользователя (`adoptDevice`): владелец в `owners.json` — объект `{dev}`, сравнение строкой не срабатывает.
- Токены устройств: срок жизни и раздел «Мои устройства» на сайте; предупреждение «подтверждайте только код со своего экрана».
- Вход по паролю — роль участника, не админа. (`PASSWORD_AUTH_ENABLED=false` уже выкидывает вошедших по паролю.)
- Совместный просмотр на сайте; надпись «Ждём, пока загрузится у …» в самом плеере ПК.
- ~~Android на общем ядре~~ — сделано (Android 2.5.0, 20.10), не проверено на устройствах:
  1. Вход по коду устройства: `LibraryStore.startDeviceAuth/pollDeviceAuth`, `X-Device-Token` в `net/Api.kt` (только свой хост), профиль — `SessionInfo`; ТВ показывает ссылку и код для телефона.
  2. «Мои фильмы»: вкладка «Мои» (`LibraryScreen(mineOnly = true)`), закладка в углу постера (`LibraryStore.setMine`).
  3. Комната: `party/Party.kt` (OkHttp, SSE-поток, очередь действий), вкладка «Вместе» (`library/TogetherScreen.kt`); гостю библиотека закрыта, как на ПК.
  4. Плеер: `player/PlayerPartySync.kt` (`PartySyncEngine.tick()` раз в 400 мс), полоса «● Вместе» у гостя, `PlayerEngine.setRate` для подстройки дрейфа.
     Ведущий свернул плеер (экран погас, другое приложение) — комната на паузе.
  Скорости воспроизведения на Android нет (`userRate` = 1). Активность в Discord на Android невозможна (у мобильного Discord нет локального IPC) — `DiscordRpc` остаётся только на ПК.
