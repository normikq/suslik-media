# Заставки, титры и умные субтитры

Общая логика — `shared/.../core/MarkersDetector.kt` (тесты `MarkersDetectorTest`), модели `MediaMarkers` / `TimeRange` — в `Model.kt`.

## Откуда берутся метки

1. **Главы файла.** Заставка — глава с названием по `INTRO_REGEX` (intro, opening, заставка, опенинг, OP…) в первой половине
   видео, до начала следующей главы (нет следующей или она дальше 5 мин — 120 с). Титры — последняя глава по `CREDITS_REGEX`
   (credits, ending, титры, ED…) во второй половине, до конца файла. Глава с обоими словами («Opening Credits») не считается.
   ПК: `chapter-list` mpv. Android: только VLC (`MediaPlayer.getChapters`); Media3 глав MKV/MP4 не отдаёт.
2. **Сервер** `GET /api/markers?title=&alt=&season=&episode=&duration=` (`/api/file/markers` — то же), только для серий
   сериала и только если в главах нет заставки или титров. `website/src/services/markers.js`: название ищется в MyAnimeList
   через Jikan (точное совпадение с одним из названий, для сезона N — «… Season N», «… 2nd Season», «… II»…), по id MAL
   AniSkip отдаёт опенинг и эндинг. Кэш `markers-cache.json` (в `DATA_DIR`) по хешу «название|сезон|серия»: найденное —
   насовсем, ненайденное — 3 дня, ошибка сети — 30 мин; не больше 20 000 записей.
   Клиенты шлют `title` = оригинальное название ИИ (если принято) или название раздачи, `alt` = название плитки.
   TheIntroSkip/TheIntroDB не подключён: публичное API не удалось проверить.

## Поведение плеера

- В заставке (если до её конца больше 2 с) — кнопка «Пропустить заставку» (ПК — ещё клавиша S). Автопропуск
  (настройка, по умолчанию выкл.): через 1,5 с в заставке перемотка на её конец и надпись «Заставка пропущена»; один раз
  на файл — если вернуться в заставку вручную, остаётся кнопка.
- На входе в титры (если они длиннее 5 с и в очереди есть следующий элемент) — карточка справа внизу:
  «Следующая серия: S01E02» или «Следующий фильм: …» (сборник), отсчёт 5/8/12 с или сразу (по умолчанию 8).
  «Включить сейчас» (ПК — Enter/Пробел), «Отмена» (Esc/Backspace, Android — «Назад») — досмотреть до конца.
  На паузе отсчёт стоит. По окончании текущий файл записывается как досмотренный. Гость комнаты «Вместе» карточку
  не получает — серию переключает ведущий. Без меток всё как раньше: карточка в конце файла.
- **Умные субтитры** (по умолчанию вкл.): если для фильма/сериала субтитры не выбирали сами — при русской речи
  форсированные русские (флаг forced или «надписи», «форсированные», «forced» в названии), иначе выключены; при
  иностранной — полные русские («Полные» первыми). Язык звука непонятен — субтитры не трогаются. При смене озвучки
  из меню правило применяется сразу, а выбор субтитров запоминается как `__smart__` (по озвучке и в следующий раз),
  пока субтитры не выберут вручную.
