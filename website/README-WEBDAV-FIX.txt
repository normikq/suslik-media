Исправление прокси WebDAV

- Используются учётные данные WebDAV на серверной стороне AllDebrid; ключ не передаётся браузеру.
- Переписывается текст XML-элементов DAV <href> и HTML-атрибутов href, чтобы навигация продолжалась через локальный подписанный прокси.
- Относительные ссылки разрешаются относительно текущей папки WebDAV, временные параметры exp/sig сохраняются.

Установите файлы проекта, сохранив собственный .env вне архива. Перезапустите сервер командой node server.js и создайте новую ссылку WebDAV на сайте. Выполнена только проверка синтаксиса; работа AllDebrid/PotPlayer в реальном окружении не проверялась.
