# Внешние озвучки (`/api/custom-audio`)

Внешняя озвучка — аудиофайл из **другой** раздачи AllDebrid, привязанный к видеофайлу фильма. Сервер хранит только связку;
сам файл клиент берёт через зеркало (`/api/file/proxy/...`) по свежей подписанной ссылке (прямые ссылки AllDebrid не отдаются).

Код: `website/src/routes/custom-audio.js`, `website/src/services/custom-audio.js`, тесты `website/test/custom-audio.test.js`.
Все запросы требуют входа (cookie или `X-Device-Token`), лимит — `apiLimiter`. Ошибка: `{ "error": "…", "code": "…", … }`.

## 1. Стандарт имён файлов озвучки

Обязателен: по имени сервер понимает, к какому фильму и серии относится дорожка. Тег `[delay=±ЧИСЛОms]` необязателен.
`+` — звук отстаёт от видео, `−` — в дорожке лишнее интро студии (звук спешит). Допустимо до ±60000 мс. Минус можно писать и как `−` или `–`. Тег языка (`[rus]`, `[en]`) — только код ISO 639: `[HQ]`, `[Dub]` языком не считаются.

| Что | Формат | Пример |
|---|---|---|
| Фильм, всё в имени | `Название.Год.[Озвучка][delay=±Nms].ext` | `Inception.2010.RedHeadSound[delay=-4200ms].mka`, `Dune.Part.Two.2024.FlarrowFilms.mka` |
| Фильм, папка | `Название Фильма (Год)/Озвучка[delay=±Nms].ext` | `Оппенгеймер (2023)/Дубляж RHS[delay=-3500ms].mka` |
| Сериал, всё в имени | `Название.SxxEyy.[Озвучка][delay=±Nms].ext` | `Severance.S01E01.HDRezka.mka`, `The.Boys.S04E08.LostFilm[delay=-1500ms].mka` |
| Сериал, сезоны | `Название Сериала/Season 01/SxxEyy.Озвучка[delay=±Nms].ext` | `Severance/Season 01/S01E01.HDRezka.mka`, `Severance/S01/S01E01.HDRezka.mka` |

- Корректно определяются фильмы с числами/годами в самом названии (`2001.A.Space.Odyssey.1968.mka`, `1917.2019.mka`).
- Технические теги (`1080p`, `x264`, `5.1`, `DDP5.1`, `DD+`, `Atmos`, `AC3`, `WEB-DL`, `640kbps` …) из названия и озвучки вычищаются.
- Тег `[rus]` в названии озвучки задаёт язык (`lang`); без него язык `rus` для кириллицы, иначе `und`.

## 2. Чекер форматов

Проверка идёт **до** сопоставления и до сохранения, по всем файлам раздачи озвучки (для `.torrent` — по списку из Bencode).

- Разрешён только `.mka`.
- Описание, обложки и контрольные суммы (`.txt .nfo .md .jpg .png .webp .gif .bmp .sfv .md5 .sha1 .sha256 .url .log .cue`) пропускаются: не мешают и не сопоставляются.
- Всё остальное — нарушение: другие аудиоформаты (`.ac3`, `.flac`, `.mp3` …), видео, исполняемые (`.exe .bat .cmd .sh` …), архивы, образы (`.iso`), прочее.
  Каждое нарушение получает `kind`: `video`, `executable`, `archive`, `image`, `other`.
- Ошибка `422`, `code: "FORBIDDEN_FILES"`, `forbidden: [{ path, ext, kind }]` (до 50), `removed: false`.
- Сервер раздачу **не удаляет** (проверка ничего не меняет): только что загруженную для проверки убирает клиент (ПК — `dropUnattached`).
- Раздачу, к которой привязаны озвучки, нельзя удалить через `/api/magnets/:id/delete|cancel`: `409`, `code: "AUDIO_ATTACHED"` (сначала удаляют дорожки).
  Если `audioMagnetId === movieMagnetId`, запрос сразу отклоняется с ошибкой `400 BAD_REQUEST`.

## 3. Сопоставление с библиотекой (fail-early)

Фильм — `movieMagnetId`; если его нет в запросе, сервер ищет готовую раздачу библиотеки по названию из имён файлов
(название раздачи, имена файлов и папок; год должен совпасть, если он есть). Если подходит несколько — `409 AMBIGUOUS` и `candidates`.
Фильм-раздача с одним видеофайлом — цель сразу; с несколькими — заметно самый большой (≥ 1,5× следующего), иначе `UNRESOLVED`.
Серия ищется по `SxxEyy`/`NxMM` в именах видеофайлов, а также по номерам серий `01.mkv` внутри папок сезонов (`Season 01`, `S01`).

Любая ошибка блокирует **всю** раздачу (частично ничего не привязывается):

| `code` | Когда |
|---|---|
| `UNRESOLVED` | по имени файла нельзя однозначно определить фильм/серию (нет названия, год или `SxxEyy`) |
| `NOT_IN_LIBRARY` (`404`) | фильм не найден в библиотеке (в том числе при указании несуществующего `movieMagnetId`) |
| `TITLE_MISMATCH` | `movieMagnetId` указан, но название/год озвучки к этой раздаче не подходят |
| `EPISODE_MISMATCH` | в озвучке есть серии, которых нет в раздаче фильма (`episodes: ["S01E10"]`) |
| `NO_VIDEO` | в раздаче фильма нет видеофайлов |
| `NOT_READY` (`409`) | раздача ещё загружается, список файлов пуст — повторить позже |
| `BAD_OFFSET` (`400`) | смещение в теге `[delay=±Nms]` или теле запроса превышает ±60000 мс |

В ответе `errors` — полный список, `error` — первое сообщение.

### 3а. Проверка по содержимому (ffprobe, 23.10)

После сопоставления по именам сервер читает заголовки файлов (`services/audio-duration.js`: `resolveDirect` + `tvstream.probeFile`,
кеш 6 ч) и сверяет озвучку с видеофайлом. В сериале проверяются до 4 пар (первая, последняя и между ними), не дольше 45 с.

| Код (`422`) | Когда |
|---|---|
| `NO_AUDIO` | в файле озвучки нет звуковой дорожки |
| `HIDDEN_VIDEO` | в файле озвучки есть видеопоток (обложка не считается) |
| `FRAME_RATE_MISMATCH` | озвучка короче/длиннее видео ровно в 25/23,976 или 25/24 раза (±10 с или 0,2 %): PAL-ускорение, звук будет убегать |
| `DURATION_MISMATCH` | разница больше 60 с или 3 % длительности видео (что больше) плюс модуль `offsetMs` — другая версия монтажа или серия |

В `errors` у этих кодов есть `audioMs`, `videoMs`, `path`, `videoPath`. Сбой чтения (нет `ffprobe`, AllDebrid не отдал файл,
не успели за 45 с) привязку не блокирует: в ответе `warnings: [{ code: "DURATION_UNCHECKED", paths }]`. У `.torrent` ссылок нет —
там всегда `DURATION_UNCHECKED`, сверка будет при `attach`. Админ библиотеки может передать `"ignoreDuration": true` (в теле
`check`/`attach`) — сверка пропускается, `warnings: [{ code: "DURATION_SKIPPED" }]`.

## POST /api/custom-audio/check

Ничего не сохраняет. Вход:

- JSON `{ "movieMagnetId": 123, "audioMagnetId": 456 }` (`movieMagnetId` необязателен);
- либо тело `.torrent` (`Content-Type: application/x-bittorrent`, ≤ 1 МБ), `?movieMagnetId=123`. Торрент только разбирается,
  в AllDebrid не загружается, поэтому привязать по нему нельзя: загрузить через `POST /api/torrents` и передать `id` как `audioMagnetId`.

Ответ `200`:

```json
{
  "ok": true, "movieMagnetId": 123, "audioMagnetId": 456, "fromTorrent": false, "attachable": true,
  "pairs": [{
    "videoPath": "Severance/Season 01/Severance.S01E01.mkv",
    "audioPath": "Severance/S01E01.HDRezka.mka",
    "voice": "HDRezka", "season": 1, "episode": 1, "offsetMs": -4200, "lang": null, "by": "file"
  }],
  "durations": [{ "videoPath": "…S01E01.mkv", "audioPath": "…S01E01.HDRezka.mka", "audioMs": 3301000, "videoMs": 3300500 }],
  "warnings": []
}
```

`offsetMs` — из тега `[delay=…]` (`null`, если тега нет), `by` — `file` или `dir` (откуда взято название).

## POST /api/custom-audio/attach

Те же проверки, что в `check`, затем сохраняет **все** пары в `audio-tracks.json`.

```json
{ "movieMagnetId": 123, "audioMagnetId": 456, "title": "HDRezka [rus]", "lang": "rus", "offsetMs": -4200 }
```

`title`, `lang`, `offsetMs` необязательны и, если заданы, заменяют вычисленные из имён файлов
(по умолчанию: озвучка из имени, язык по названию, задержка из тега или 0). Повтор уже сохранённой связки ничего не дублирует.
Ответ `201` (создано) или `200` (всё уже было): `{ ok, movieMagnetId, created: [track], existing: [track], warnings }`.
Ошибки: `400` (`BAD_OFFSET`, `BAD_REQUEST`), `409 LIMIT` (до 50 озвучек на один видеофайл, 5000 всего), `422 BAD_PATH` (путь видео длиннее 600 символов), плюс все из разделов 2–3а.
`offsetMs` из тела при сверке длительности заменяет теги.

## GET /api/custom-audio/:magnetId

Дорожки фильма (`:magnetId` — раздача с фильмом) со **свежей подписанной ссылкой** зеркала (живёт `MIRROR_TTL`, 12 ч).

```json
{ "magnetId": 123, "tracks": [{
  "id": "trk_9f83a1b0", "movieMagnetId": 123,
  "videoPath": "Severance/Season 01/Severance.S01E01.mkv",
  "audioMagnetId": 456, "audioPath": "Severance/S01E01.HDRezka.mka",
  "title": "HDRezka [rus]", "lang": "rus", "offsetMs": -4200,
  "addedBy": "u_100", "addedByName": "Имя", "createdAt": 1729613000000, "mine": true,
  "url": "https://<сайт>/api/file/proxy/S01E01.HDRezka.mka?link=…&exp=…&sig=…"
}] }
```

`mine` — можно ли менять смещение. Дорожка, у которой раздачу озвучки убрали из AllDebrid, в список не попадает.
Запрос открывает фильм: `markOpened` продлевает хранение раздачи с фильмом и раздач с озвучками.

## PUT /api/custom-audio/:trackId/offset

Тело `{ "offsetMs": -250 }`, целое число мс, не больше ±60000. Автору дорожки и админу Discord (общий пароль админом не считается).
Ответ `{ ok, id, offsetMs }`. Ошибки: `400 BAD_OFFSET`, `403`, `404`.

## DELETE /api/custom-audio/:trackId

Удаление внешней озвучки. Права такие же, как у изменения смещения: автору дорожки (`mine: true`) или администратору медиатеки Discord.
Ответ:
```json
{ "ok": true, "id": "trk_9f83a1b0", "removedAudioMagnet": true }
```
- Если у связанной раздачи озвучки (`audioMagnetId`) не осталось других дорожек, привязанных к медиатеке, и добавил её этот же пользователь/устройство (запись в `owners.json`), сервер автоматически удаляет её из AllDebrid (`removedAudioMagnet: true`).
- Если раздача с фильмом или раздача озвучки добавлена кем-то другим, либо ещё используется другими дорожками — раздача в AllDebrid остаётся (`removedAudioMagnet: false`).
- Ошибки: `401 Unauthorized`, `403 FORBIDDEN` («Удалять дорожку может автор дорожки или админ.»), `404 NOT_FOUND` («Дорожка не найдена.»).

## 4. Хранилище `audio-tracks.json` (`DATA_DIR`)

Запись атомарная через `makeJsonWriter`. Ключ — `"targetMagnetId|targetVideoPath"`:

```json
{
  "1234567|Severance/Season 01/Severance.S01E01.mkv": [{
    "id": "trk_9f83a1b0", "audioMagnetId": 7654321, "audioPath": "Severance/S01E01.HDRezka.mka",
    "title": "HDRezka [rus]", "lang": "rus", "offsetMs": -4200, "addedBy": "u_discord_id", "createdAt": 1729613000000
  }]
}
```

`addedBy` — `u_<id>` (Discord) или `dev_<cookie sdev>` (вход по общему паролю).

## 5. Жизненный цикл

- Фильм открыли (`markOpened` из плейлиста, `mirror-url`, `file/unlock`, `GET /api/custom-audio/:id`) — тем же вызовом
  продлевается срок и у раздач с его озвучками (`LIBRARY_IDLE_DAYS`).
- Фильм удалён из библиотеки (`cleanup.forget`) — удаляются его записи из `audio-tracks.json`.
  Удалена раздача с озвучкой — пропадают дорожки, которые брали файлы из неё.

## 6. Общий модуль (`shared/`, 23.10)

`shared/src/main/kotlin/ru/suslikovanora/media/core/audio/CustomAudio.kt` — то, что одинаково на ПК и Android (сети нет:
приложения сами делают запросы и отдают ответ сюда):

- `CustomTrack` — дорожка фильма; `menuName` — название в меню, «HDRezka [rus]» (без названия — имя файла, `lang: "und"` — без языка).
- `CustomPair`, `CustomCheck` — пары и результат `check`.
- `CustomAudio`: адреса (`tracksPath`, `trackPath`, `offsetPath`, `CHECK_PATH`, `ATTACH_PATH`) и тела (`checkBody`, `offsetBody`);
  разбор ответов (`parseTracks` — дорожки без `url` пропускаются, `parseCheck`, `parseAttached`); `forVideo` (по ключу «magnetId|path»),
  `byMenuName` (дорожка по названию в меню плеера), `infoJson` — `{"<подписанная ссылка>": {"title", "offsetMs"}}` для плеера Android.
- `CustomAudioIndex` — название и задержка по ссылке: ключ `MirrorLink.fileKey` (новая подпись — тот же файл) и адрес через `BurstProxy` (`noteWrapped`).

Тест: `shared/src/test/.../CustomAudioTest.kt`. В приложениях остаются сеть, кеш, тексты ошибок, интерфейс и применение задержки к движку.

## 6а. Android-клиент (23.10, поверх 2.5.1)

Только воспроизведение: добавлять, менять смещение и удалять дорожки на Android нельзя.

- **Список.** `PlaySheet` («Смотреть») вместе со ссылкой зеркала запрашивает `GET /api/custom-audio/<magnetId>`, разбирает ответ
  `CustomAudio.parseTracks` (только ссылки `https://`) и раскладывает дорожки по `videoPath`. Ошибка запроса — фильм открывается без них. Ссылки дорожек текущей серии добавляются к озвучкам
  из раздачи (`audioUrls`). У следующих серий плейлиста дорожки лежат в `episodeSides` под ключом `signed` (уже подписаны,
  `PlayerTrackSelector.signSidecars` берёт их как есть).
- **Имя и смещение.** Отдельный extra `PlayerExtras.CUSTOM_AUDIO` (`CustomAudio.infoJson`).
  Его читает `player/CustomAudioInfo` — экземпляр общего `CustomAudioIndex`. В меню звука загруженная
  озвучка подписана `menuName` («HDRezka [rus]», как на ПК), а не именем файла.
- **Знак смещения** как на ПК (`audio-delay` mpv): `+2000` — звук начинается на 00:02 видео, `−5000` — первые 5 с дорожки пропускаются.
- **Только `.mka`** (`CustomAudio.isSupported`, общий модуль; старые записи с другим форматом пропускаются): у контейнера есть индекс,
  оба движка перематывают его сами. Поэтому с 23.10 нет отдельного ExoPlayer рядом с VLC (`SideAudio.kt`) и перемотки по постоянному
  битрейту в Media3: они были нужны только для голого `.aac`.
- **Медиатека.** Раздача, в которой только `.mka`, отдельной плиткой не показывается (`LibraryStore.isVoiceOverOnly`, как на ПК).
- **Media3.** Озвучка — ещё один источник `MergingMediaSource`; при `offsetMs ≠ 0` он обёрнут в `player/OffsetMediaSource.kt`
  (сдвигает все времена источника на `offsetMs`, на открытом API Media3: `WrappingMediaSource` + своя обёртка `MediaPeriod`).
  `setAudioDelayMs` у Media3 ничего не делает — сдвиг уже в источнике.
- **VLC.** Озвучка — slave, как озвучки из раздачи: при открытии — в `Media` (`VlcEngine`, `m.audioFiles`), во время просмотра —
  `addAudioFile`. При выборе загруженной `PlayerTrackSelector.syncAudioDelay`
  ставит её `offsetMs` в `setAudioDelay`, при выборе дорожки фильма — 0. Какая дорожка из какого файла — по порядку: дорожки файлов
  идут после дорожек фильма в порядке подключения. Сдвиг на 1 с и больше — перемотка на текущее место (`VlcEngine.setAudioDelayMs`), чтобы звук не ждал, пока видео догонит сдвиг.
- Проверено 23.10 на SM-S936B (Suslik Debug) только с `.aac` — вариант с `.mka` на устройстве ещё не проверен
  (особенно отрицательный сдвиг в VLC: с `.aac` VLC не мог перемотать файл и звука не было).

## 7. Клиент ПК (`desktop/`)

Код: `CustomAudio.kt` (запросы, кеш дорожек, удаление не привязанных раздач, тексты ошибок; разбор и модели — из `shared/`, раздел 6), `AudioAttachView.kt` (экран), плеер — `player/PlayerView.kt`,
`player/MpvEngine.kt`, меню — `player/PlayerOverlays.kt`. Строки — `resources/strings/ru.json` (`audio.*`, `player.*ozvuchk*`).

**Только `.mka`.** Сервер принимает и отдаёт озвучки только в `.mka` (раздел 2): у контейнера есть индекс, mpv перематывает его точно,
задержку делает `audio-delay`. ПК проверяет это и сам (`CustomAudio.isSupported` в `shared/`): дорожка из `GET` не с `.mka` (старая запись) пропускается,
раздача, где есть что-то кроме `.mka` (описание и обложки не в счёт), сервером отклоняется ещё на проверке (`FORBIDDEN_FILES`), и ПК удаляет её из AllDebrid, если сам её загрузил.

### 7.1. «Добавить» → «Озвучка»

- Принимаются раздачи только с `.mka`. Сразу несколько раздач: magnet-ссылки через пробел или перенос строки, несколько `.torrent` в диалоге или перетаскиванием на экран.
  Каждая раздача — своя карточка: проверка, `[✓] Файлы валидны (только аудио)` / `[✗]` со списком лишних файлов (всё, что не `.mka`), выбор фильма при `AMBIGUOUS`
  (поля варианта: `magnetId`/`id`, `name`/`title`), таблица «файл → фильм/серия (с постером) → дорожка → задержка», «Привязать»; «Привязать все (N)», когда готовых больше одной.
- Порядок: `.torrent` сначала проверяется на сервере без загрузки (`check` с телом торрента), затем раздача загружается в AllDebrid (`POST /api/torrents` или `/api/magnets`),
  клиент ждёт готовности (`/api/magnets/:id`, `statusCode 4`) и повторяет `check` по `audioMagnetId`.
- «Задержка для всех серий» (если строк больше одной) подставляет число во все строки; любую строку можно поправить отдельно.
- Задержка из таблицы, отличная от вычисленной сервером, после `attach` сохраняется каждой дорожке через `PUT …/offset`.
- **Предпросмотр** (▶ у строки): обычный плеер, серия с начала, эта озвучка выбрана (`PlayRequest.preview`), задержка подгоняется `[` `]` (±100 мс), `\` — сброс;
  значение сразу возвращается в строку (`onPreviewDelay`). Прогресс просмотра и задержка на сервер в предпросмотре не пишутся. Файлы берутся по ссылкам зеркала (`/api/file/mirror-url`).

### 7.2. Загруженные, но не привязанные раздачи

- Раздача загружается в AllDebrid сразу (нужна для предпросмотра) и записывается в `audio_pending.properties`.
- Удаляется (`/api/magnets/:id/delete`, при ошибке — `/cancel`), если: нажали «×»; в ней лишние файлы; ушли с вкладки «Добавить» (предпросмотр вкладку не закрывает);
  приложение закрыли раньше — тогда при следующем запуске, после первой загрузки медиатеки (`CustomAudio.cleanupPending`).
- **Не удаляется никогда**, если раздача уже была в AllDebrid до этого экрана (тот же хеш: AllDebrid возвращает существующую — она есть в медиатеке или среди раздач с озвучками)
  или к ней привязаны озвучки, которые клиент видел за этот запуск. Совпадение — по раздаче, не по содержимому: та же озвучка в торренте с другим хешем удалится.

### 7.3. Медиатека

Раздача, в которой только файлы `.mka`, на ПК отдельной плиткой не показывается (`Library.voiceOvers`; нужна предпросмотру).

### 7.4. Плеер

- Дорожки фильма (`GET /api/custom-audio/:magnetId`, кеш на запуск, ожидание до 3 с) (только `.mka`) добавляются после озвучек раздачи через `BurstProxy` и `audio-add url auto title lang`;
  в меню — `menuName` (`title [lang]`), дорожку по выбранному названию находит `CustomAudio.byMenuName`. Настройка «Озвучки пользователей: Показывать / Скрыть» (`settings.properties`, `custom_audio_off`) выключает их загрузку.
- Задержка **абсолютная, от 00:00 видео**: −5000 — на 00:00 видео звучит 00:05 дорожки (интро пропущено), +2000 — звук с 00:02. Не складывается с задержкой фильма;
  при выборе другой дорожки возвращается задержка фильма. Своя поправка `[` `]` хранится на ПК для этой дорожки (`player_ui`, `adelay:<trackId>`), предел ±60 с.
- mpv не перечитывает дорожку при новой `audio-delay`: без перемотки звука нет, пока видео не уйдёт на величину сдвига (проверено 23.10 на libmpv: +10 с → 10 с тишины).
  Поэтому при изменении задержки на 1 с и больше плеер перематывает на текущее место.
- Когда видео кончилось, а дорожка длиннее, плеер ставит паузу и считает серию досмотренной.
- Меню звука: «💾 Запомнить задержку для всех» (`PUT …/offset`) и «🗑 Удалить озвучку» (`DELETE`, второе нажатие подтверждает; дорожка убирается из mpv, `audio-remove`) —
  только при `mine: true`. Удаление — по одной серии.
- Журнал: тег `[custom-audio]` (сколько дорожек пришло, применённая задержка, обрезка конца, удаление).

## 8. Телевизор (`tizen/`, 23.10, ТВ 0.2.7)

AVPlay второй файл звука не подключает, поэтому озвучку с видео склеивает сервер — тот же поток для ТВ, что для DTS/Blu-ray
(`/api/file/tv`, `website/README.md`, «Поток для телевизора»), только звук из второго входа ffmpeg.

- `GET /api/file/tv-info?link=&name=` + `&ext=<ссылка>` (повторяется, до 8 — файлы озвучек из той же раздачи) и
  `&magnetId=<раздача>&path=<путь видео>` (озвучки пользователей этого видео, до 20; `services/custom-audio.js` → `trackLinks`).
  В ответе `external: [{ kind: "file", link, offsetMs: 0, url }, { kind: "custom", id, title, lang, offsetMs, url }]`.
  Ошибка AllDebrid — ответ без озвучек пользователей.
- Поток: `/api/file/tv/<имя>?link=&x=<ссылка на файл озвучки>&xo=<сдвиг>&exp=&sig=` вместо `&a=`. Подписаны и файл, и сдвиг
  (`tvstream.externalKey`). ffmpeg: видео фильма копией, звук из файла озвучки (AC3/AAC/E-AC3/MP3 — копией, остальное → AC3).
  Сдвиг — как на ПК: место в дорожке = место в видео − `offsetMs` (`-ss` второго входа), до начала звука — `-itsoffset`.
  Поток обрезается по длине видео (`-t`): длинная дорожка не играет на чёрном экране.
  Если у озвучки есть `-ss` (сдвиг − или перемотка), звук всегда перекодируется в AC3: копия звука второго входа с `-ss` в ffmpeg 6.1
  ставила видео позже звука на величину `-ss` (на ТВ в начале было слышно интро, 23.10). Без `-ss` AC3/AAC/E-AC3 копируются.
- Плеер ТВ: меню звука (↓) → «Озвучки отдельным файлом» (из раздачи — по хвосту имени или папке, пользователей — `customName`,
  как `menuName` на ПК; только `.mka`). Выбор открывает поток с сервера с текущего места; выбор запоминается для раздачи
  (`localStorage` `tv_dub`, по названию в меню) — следующие серии сразу открываются с ней (список пользователей ждём до 3 с).
  Дорожка фильма в меню выбор сбрасывает. Сервер не смог — фильм открывается без озвучки.
- Раздачи только с `.mka` (озвучки) в медиатеке ТВ плиткой не показываются (`model.isVoiceOverOnly`, как на ПК).
- Старый сервер (без `external` в `tv-info`) ТВ узнаёт и пишет «сервер нужно обновить»; новый сервер пишет в журнал `[tv]`,
  если у раздачи есть озвучки пользователей, а к этому видео не нашлось ни одной (с путями видео из привязок). `SERVER_REV` — `2026-10-23 tv-dubs`.
- Тесты: `website/test/tv-external-audio.test.js` (аргументы, подпись, `trackLinks`, маршрут с настоящим ffmpeg: FLAC → AC3,
  сдвиг +2 с, длина по видео), `tizen/test/model.test.js`. На телевизоре не проверено.
