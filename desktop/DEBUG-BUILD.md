# Отладочная сборка «Suslik Debug» для Windows

Отдельное приложение для поиска проблем. Код тот же, что у обычного, но сборка пишет подробный журнал.
Как и на Android:

- ставится **рядом** с обычным Suslik Media (свой ярлык «Suslik Debug», своё место установки) и ничего в нём не трогает;
- свои вход, настройки, прогресс просмотра и журнал — в `%APPDATA%\SuslikMediaDebug`;
- свой запас фильма во временной папке (`SuslikDebug-stream`), так что оба приложения можно держать открытыми;
- сама не обновляется: новую версию ставят с компьютера.

## Где взять

- GitHub → Actions → «Windows MSI» → Run workflow с галочкой **debug** → артефакт **windows-debug-msi**
  (`Suslik Debug-<версия>.msi` внутри zip).
- Или собрать самому: в папке `desktop` выполнить `./gradlew packageMsi -Pdiag` →
  `build/compose/binaries/main/msi/Suslik Debug-<версия>.msi`.

Установка — обычный двойной щелчок по `.msi`.

## Что пишет журнал

Файл `%APPDATA%\SuslikMediaDebug\player.log` (до 20 МБ, затем старая часть — `player.old.log`).

| Тег | Что |
|---|---|
| `[sys]` | раз в 5 с при открытом фильме, иначе раз в минуту: питание (сеть / батарея %, только ноутбуки), загрузка процессора приложением и всем ПК, самые занятые потоки, память, трафик запаса |
| `[net]` | сетевые адаптеры: какие подключились и отключились (Wi‑Fi ↔ Ethernet, VPN) |
| `[http]` | каждый запрос к серверу: код ответа, время, размер |
| `[vlc]` | раз в 5 с: позиция, буферизация, прочитано, кадры показаны / потеряны, звук |
| `[proxy]` | раз в 5 с: окна запаса (сколько впереди, качает или отдыхает) |
| `[mark]` | метка: **F8** в плеере или «Метка» в настройках — в момент проблемы |

Плюс всё, что пишет обычный журнал плеера: открытие, перемотки, буферизация, рывки запаса, действия сторожа.

## Как проводить опыт

1. Откройте фильм, смотрите как обычно.
2. Заметили проблему — сразу нажмите **F8** (в углу появится «📍 Метка #N»).
3. Потом «Настройки → Отладочная сборка → Архив»: на рабочем столе появится `suslik-debug-ДДММ-ЧЧММ.zip`.
   Его и присылайте; разбор начинается с нужной метки.

Собственный журнал VLC не подключается: его обработчик однажды ронял приложение на Windows (см. `PlayerLog.kt`).
